Instalação no Termux

1. Entrar na pasta da ferramenta

cd ~/Js-links-videos

2. Instalar o Python

pkg install python -y

3. Instalar o yt-dlp

python -m pip install -U yt-dlp

4. Configurar o armazenamento

termux-setup-storage

Aceite a permissão de acesso aos arquivos no Android.

5. Iniciar o JS LINKS VIDEOS

python jslinks.py

Atualização

Para atualizar o yt-dlp:

python -m pip install -U yt-dlp

Pasta dos downloads

Os vídeos são salvos em:

~/storage/downloads/JS-LINKS-VIDEOS
